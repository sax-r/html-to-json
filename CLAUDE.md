# Claude Code Instructions

2. **Save tokens** — Keep responses short and concise. Skip explanations unless asked. Prefer targeted edits over full-file rewrites.

3. **Don't fix what isn't broken** — Only touch code that is directly related to the task. No refactoring, cleanup, or improvements unless explicitly requested.
